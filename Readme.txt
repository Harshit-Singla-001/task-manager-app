A C++ OS(Operating Systems) project.

A Command Line Interface Task Manager(NO GUI) 

How To Run the code:-

    For C++ CLI version:
    1. Run this Command --> g++ -static main.cpp ProcessList.cpp -o task_manager -lpsapi
    2. Run the generated task_manager.exe.

    For Python GUI (Qt) version:
    1. Make sure Python is installed.
    2. Install libraries: pip install PySide6 psutil
    3. Run this Command --> python task_manager.py
