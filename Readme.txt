A C++ OS(Operating Systems) project.

A Command Line Interface Task Manager(NO GUI) 

How To Run the code:-
    1. Open the folder in Ide(vscode).
    2. Run this Following Command --> g++ -static main.cpp ProcessList.cpp -o task_manager -lpsapi
    3. This will generate a portable exe file named task_manager.exe (static linking ensures it runs on any Windows system without missing DLL errors). Run it to get your task manager running.
